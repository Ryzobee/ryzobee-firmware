# RyzoBee 配色与字体规范
## Color & Typography Guidelines

---

# 1. 品牌配色系统
## Brand Color System

RyzoBee 的品牌配色以 **Black / White / Orange** 为核心，通过高对比度、低装饰性的色彩系统体现现代、工程、设计与快速响应的品牌气质。

品牌色彩原则：

**Black defines the space.  
White carries the information.  
Orange creates recognition.**

即：

**黑色构建空间，白色承载信息，橙色建立识别。**

---

# 2. 品牌主色
## Primary Brand Color

### RyzoBee Orange

**HEX**  
`#FF6A00`

**RGB**  
`255 / 106 / 0`

**CMYK 建议值**  
`0 / 65 / 100 / 0`

> CMYK 最终数值应根据实际印刷纸张、油墨与 ICC Profile 打样校准。

RyzoBee Orange 是品牌最重要的识别色，用于建立视觉焦点。

主要应用：

- Brand Logo
- CTA Button
- Key Message
- Product Highlight
- Key Interface
- Packaging Accent
- Selected State
- Key Graphic Element
- Social Media Highlight
- Exhibition Signage

品牌橙的作用是：

**Highlight / Emphasis / Recognition**

而不是作为大面积背景色使用。

### 使用原则

推荐：

- 黑色背景 + 橙色强调
- 白色背景 + 橙色局部强调
- 产品黑灰主体 + 橙色细节

不推荐：

- 整页纯橙背景
- 大面积橙色正文
- 多种高饱和色与品牌橙同时竞争
- 将品牌橙作为 Warning 或 Error 的唯一状态颜色

# 4. 推荐色阶

为保证官网、软件 UI、包装与宣传材料统一，建议建立以下标准灰阶：

| Token | HEX | 建议用途 |
|---|---|---|

| Black 90 | `#121212` | 页面背景 |

# 6. 品牌橙与 Warning 色的区别

RyzoBee Orange：

`#FF6A00`

代表：

**品牌 / 操作 / 重点 / 选择**

Warning：

`#FFB020`

代表：

**风险 / 注意**

两者不得混用。

例如：

正确：

`FLASH FIRMWARE`  
使用 Brand Orange

`POWER SUPPLY WARNING`  
使用 Warning Yellow

错误：

所有警告、按钮、Logo、选中状态全部采用相同橙色。

# 9. 字体系统
## Typography System

RyzoBee 字体系统分为两类：

**Display Typography**

用于品牌效果字、营销标题、产品名称。

字体：

**Teko**

以及：

**Information Typography**

用于中文、英文正文、UI、参数、技术资料。

字体：

**Noto Sans**

中文使用：

**Noto Sans SC**

---

# 10. 品牌效果字体
## Display Typeface

### Teko

Teko 是 RyzoBee 的主要品牌效果字体。

主要用于：

- Hero Title
- Campaign Headline
- Product Name
- Packaging Headline
- Exhibition
- Poster
- Video Title
- Social Media
- Large Number
- Promotional Message

Teko 具有：

- 窄体结构
- 高视觉效率
- 明确纵向比例
- 工业化特征
- 强展示性

因此适合作为 RyzoBee 的品牌视觉字体。

---

# 11. Teko 字重

推荐使用：

**Teko Medium — 500**

用于一般视觉标题。

**Teko SemiBold — 600**

用于主要标题。

**Teko Bold — 700**

用于 Hero、产品名和宣传视觉。

不建议大量使用 Light 字重作为核心品牌标题。

---

# 12. Teko 使用规范

推荐使用：

**ALL CAPS**

例如：

ROOTMAKER

MAKE IT REAL

BUILD SOMETHING

CONNECT. BUILD. SHARE.

---

混合大小写也可用于产品名称：

RootMaker

RootMerlin

但在强品牌视觉场景中：

**ROOTMAKER**

通常优先于：

RootMaker

---

# 13. Teko 字距

由于 Teko 本身较窄，英文全大写时可以增加少量 Tracking。

推荐：

Hero：

`0% ~ +3%`

Section Title：

`+2% ~ +5%`

Small Label：

`+5% ~ +10%`

例如：

`R O O T M A K E R`

不建议极端扩大字距。

---

# 14. Teko 行距

Teko 的视觉高度较高，因此标题行距应相对紧凑。

推荐：

### Hero

Line Height：

`85%–100%`

例如：

72 px 字号

建议：

65–72 px 行距

---

### Multi-line Headline

建议控制在：

`90%–105%`

避免使用 120% 以上宽松行距。

---

# 15. Teko 禁止使用

Teko 不建议用于：

- 大段正文
- 中文
- UI 参数
- Datasheet
- 长篇技术说明
- 小于 12 px 的界面文字
- 法务文字

品牌效果字体用于：

**表达情绪与层级**

而不是承担大量信息。

---

# 19. 中英文混排原则

中英文混排时：

中文：

**Noto Sans SC**

英文正文：

**Noto Sans**

效果型英文：

**Teko**

例如：

### 正确

**ROOTMAKER**  
快速开始使用你的第一个 RyzoBee 项目。

其中：

ROOTMAKER → Teko

中文正文 → Noto Sans SC

RyzoBee → Noto Sans

---

不建议：

在中文正文中将所有英文单词切换为 Teko。

Teko 仅承担视觉标题角色。

# 33. 字体禁止事项

禁止：

- 随意增加第三种品牌主字体
- 使用装饰性中文字体
- 使用手写字体
- 使用圆润卡通字体
- 正文使用 Teko
- 强行将中文横向压缩模仿 Teko
- 同一个页面使用超过 4 个字重
- 中英文使用完全不同风格的正文字体
